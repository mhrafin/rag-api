# Proposal

Replace current background task in `src/routers/documents.py` with a relay service. This relay service will be a seperate worker container, an independent process. It will poll [outbox_event table](2.1-FR-add-an-outbox-table-for-transactional-outbox-pattern.md) and call appropriate functions for chunking or embedding.

It needs to survive API restarts and scale independently.
